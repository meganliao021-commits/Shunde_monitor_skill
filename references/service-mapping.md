# 事件 → 服务映射规则

基于顺德区上市公司合作推荐报告，建立事件类型与营业部可推服务的直接映射。

---

## 1. 股权激励

### 公告特征
标题含"股权激励"、"限制性股票"、"股票期权"、"激励计划"

### ToB 服务包
- 方案架构设计（限制性股票 vs 股票期权选择、激励比例、分期安排）
- Black-Scholes 定价（期权价值测算）
- 业绩考核设计（ROE / 营收增速 / 净利润复合指标）
- 交易所申报全套材料
- 行权托管执行（资金划付、股份登记）
- 税务筹划（授予 / 行权 / 出售三环节最优）

### ToC 延伸
- 员工持股账户开立（每个激励对象都需要证券账户）
- 行权融资（员工没钱行权时提供融资）
- 个人税务筹划
- 减持节奏规划（高管限售股解禁后如何减持）

### 收费参考
- 设计费：100-500 万
- 托管费：0.3%/年
- 行权融资：按融资规模收息（6-8%/年）

### 关键切入点
- 首次激励 = 方案设计空白期（高价值）
- 解锁期 = 行权融资需求（高时效）
- 回购注销 = 税务清算需求（持续性）

## 2. 员工持股计划

### 公告特征
标题含"员工持股"

### ToB 服务包
- 持股计划账户管理（员工出资归集、资金管理）
- 划付指令执行（买入/卖出/过户）
- 定期信息披露合规
- 税务筹划

### ToC 延伸
- 参与员工开立证券账户
- 后续财富管理服务（产品推荐、资产配置）
- 减持规划

### 收费参考
- 托管费：100-300 万/年
- 员工账户开户：佣金收入
- 后续财富管理：代销费分成

### 关键切入点
- 首次设立 = 托管账户管理（高价值）
- 购买期 = 资金归集与划付（高时效）
- 存续期 = 持续信息披露与税务服务（持续性）

---

## 3. 股份回购

### 公告特征
标题含"回购"（排除"逆回购"、"国债回购"）

### 子类型判断
- **回购注销**：标题含"注销"或"减少注册资本"
- **回购用于员工持股/激励**：标题含"员工持股"或"股权激励"
- **回购其他用途**：市值管理、稳定股价

### ToB 服务包
- 回购专户托管（开立回购专用证券账户）
- 资金划付（回购资金托管、交易指令执行）
- 注销登记协同（与中证登沟通、工商变更）
- 税务清算（印花税、资本利得税最优方案）
- 预案设计咨询（回购金额/价格/用途策略）
- 后续激励对接（如果回购用于员工持股/股权激励）

### ToC 延伸
- 股东权益管理
- 分红再投资对接
- 后续减持服务

### 收费参考
- 托管费：0.3-0.5%/年（按回购规模）
- 预案设计费：协商
- 后续激励对接：设计费+托管费

### 关键切入点
- 回购预案公告 = 专户托管开户（高时效）
- 回购实施期 = 资金划付与交易执行（持续性）
- 回购完成 = 注销登记或激励对接（高价值）

## 4. 委托理财（闲置资金）

### 公告特征
标题含"委托理财"、"闲置资金"、"闲置自有资金"、"理财产品"、"进行委托"

### ToB 服务包
- 机构现金管理（华泰资管产品、短期理财）
- 对公理财产品代销（银行理财、结构性存款、券商资管）
- 资金配置方案设计（流动性管理、收益率优化）
- 税务筹划（理财收益税务处理）

### 收费参考
- 管理费分成（华泰资管产品）
- 代销费（按规模，约 0.1-0.3%/年）
- 配置顾问费：协商

### 关键切入点
- 首次公告 = 资金规模评估与产品推荐（高时效）
- 滚动购买 = 持续产品推荐与资金配置（持续性）
- 到期再投资 = 再配置方案（持续性）

## 优先级评分模型

| 维度 | 权重 | 评分说明 |
|---|---|---|
| 市值 | 30% | 市值越大，营业部可承接的业务规模越大，优先级越高 |
| 现有覆盖深度 | 25% | 零覆盖 = 5分，浅覆盖 = 3分，深覆盖 = 1分 |
| 业务机会 | 25% | 事件规模越大、涉及金额越高、业务链条越完整 = 5分 |
| 净利润 | 10% | 净利润规模反映公司支付能力 |
| 政策契合度 | 10% | 与当前监管政策/市场热点契合度 |

**优先级分级**：
- ★★★★★（4.5-5.0）：立即上门，争取首单
- ★★★★（3.5-4.5）：积极跟进，争取突破
- ★★★（2.5-3.5）：定期跟进，等待机会
- ★★（1.5-2.5）：保持联系，长期培育
- ★（1.0-1.5）：基础维护，不投入大量资源
