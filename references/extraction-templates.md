# AI 文本分析字段模板

针对四类公告，定义标准化抽取字段。AI 在分析公告时应按对应模板提取结构化数据。

---

## 1. 股权激励

### 核心字段（必须抽取）
- **激励方式**：限制性股票 / 股票期权 / 组合
- **授予数量**：总股数（如 12,630,000 股）
- **授予价格**：每股价格（元）（如 28.14 元/股）
- **激励对象人数**：人数（如 199 人）
- **业绩考核条件**：ROE / 营收增速 / 净利润增长率等具体指标
- **锁定期**：限制期长度（如 48 个月）
- **有效期**：计划总有效期（如 60 个月）
- **行权安排**：分几期行权，每期比例（如 三期：40%/30%/30%）

### 辅助字段（尽量抽取）
- **回购注销条款**：离职/不达标时的回购价格
- **调整条款**：分红/配股/转增后授予价格如何调整
- **高管参与情况**：董监高是否参与、参与人数
- **资金来源**：员工自筹 / 公司奖励基金

### 分析要点
- 是否为首次激励？（首次激励 → 方案设计机会）
- 是否达到解锁/行权条件？（解锁 → 行权融资需求）
- 是否触发回购注销？（回购注销 → 税务清算需求）
- 授予价格 vs 当前股价的溢价/折价比例

---

## 2. 员工持股计划

### 核心字段（必须抽取）
- **计划规模**：总规模（万元）
- **参与人数**：预计参与人数
- **资金来源**：员工自筹 / 公司奖励基金 / 组合
- **存续期**：计划存续期限（如 36 个月）
- **管理方式**：自行管理 / 委托管理（如信托计划）
- **购买价格**：每股购买价格（如有，或市价）
- **锁定期**：持股锁定期（如 12 个月）

### 辅助字段（尽量抽取）
- **考核条件**：是否与公司业绩挂钩（如 ROE 要求）
- **资金来源明细**：员工出资比例、公司借款比例
- **管理机构**：信托公司名称（如委托管理）
- **历史计划**：是否已有前期员工持股计划

### 分析要点
- 是否为首次设立？（首次 → 托管账户管理机会）
- 计划规模 vs 公司市值比例（反映激励力度）
- 参与人数 × 人均出资额（可估算 ToC 客户规模）
- 是否使用杠杆（杠杆 → 融资服务需求）

---

## 3. 股份回购

### 核心字段（必须抽取）
- **回购金额区间**：最低-最高金额（万元）
- **价格上限**：每股回购价格上限（元）
- **回购用途**：注销 / 员工持股 / 股权激励 / 其他（市值管理）
- **回购期限**：起止日期
- **已回购金额**：截至目前已回购金额（万元）
- **已回购数量**：截至目前已回购股数
- **回购资金来源**：自有资金 / 募集资金

### 辅助字段（尽量抽取）
- **回购进度**：完成百分比
- **回购均价**：已回购部分的平均价格
- **回购方式**：集中竞价 / 要约回购 / 其他
- **董事会/股东会批准情况**：是否已获批准

### 分析要点
- 回购规模 vs 公司市值比例（反映回购力度）
- 回购价格上限 vs 当前股价（判断回购紧迫性）
- 回购用途（注销 → 税务清算；激励/员工持股 → 后续方案设计）
- 回购进度（快完成 → 后续激励对接需求）
- 是否首次回购？（首次 → 专户开户需求）

---

## 4. 委托理财（闲置资金）

### 核心字段（必须抽取）
- **产品类型**：银行理财 / 信托计划 / 券商资管 / 结构性存款 / 国债逆回购
- **理财金额**：总金额（万元）
- **预期收益率**：年化收益率（如 2.5%-3.0%）
- **期限**：产品期限（如 90 天、6 个月）
- **资金来源**：闲置募集资金 / 闲置自有资金
- **受托方**：受托机构名称（如 XX 银行、XX 券商）
- **风险等级**：低风险 / 中低风险 / 中风险

### 辅助字段（尽量抽取）
- **是否滚动购买**：是 / 否（滚动 → 持续服务需求）
- **审批层级**：董事会 / 股东会（大额需股东会）
- **历史理财规模**：累计已购买金额
- **资金占净资产比例**：反映公司现金充裕程度

### 分析要点
- 理财规模 vs 公司净资产比例（反映资金充裕度）
- 收益率水平（低收益率 → 有优化空间，可推华泰资管产品）
- 是否滚动购买（滚动 → 持续产品推荐机会）
- 资金来源（募集资金 → 监管更严格，需合规方案；自有资金 → 更灵活）
- 受托方是否为华泰（非华泰 → 有替代空间）

---

## 通用分析字段（所有类型）

- **公告日期**：YYYY-MM-DD
- **公告类型**：股权激励 / 员工持股 / 股份回购 / 委托理财
- **事件性质**：首次 / 进展 / 完成 / 调整 / 终止
- **涉及金额**：（万元）
- **公司市值**：最新市值（亿元）
- **优先级评分**：按评分模型计算（1-5 星）
- **合作机会摘要**：一句话概括核心商机
- **推荐服务包**：ToB 服务 + ToC 延伸
- **预估收费**：按服务映射规则估算
- **跟进建议**：何时跟进、找谁、怎么切入
